Galerie de Templates
Chargez vos images de tickets · Détection automatique du carré blanc · Injection du QR code
🔬
Moteur de détection — Style "Tiger"
Canvas CV actif
Le moteur scanne l'image pixel par pixel via Canvas 2D API (équivalent OpenCV en navigateur) : il détecte le contour du carré blanc dominant, récupère ses coordonnées (x,y,w,h), puis redimensionne et positionne le QR exactement dans la zone détectée. Résultat : zéro carré blanc visible sur le ticket final.
